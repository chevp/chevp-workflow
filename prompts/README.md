# prompts/

Curated prompts for generating assets and copy related to `chevp-workflow`.

These are **source prompts** — edit them to improve quality, then regenerate the assets they produce. They are not runtime prompts used by the framework's lifecycle.

## Files

| File | Purpose |
|:-----|:--------|
| [framework-image.md](framework-image.md) | Hero/overview image of the workspace layer and its relation to chevp-ai-framework |
| [layering-diagram.md](layering-diagram.md) | Stack diagram (workspace → per-repo → domain → project) |
| [lifecycle-diagram.md](lifecycle-diagram.md) | Discover → Coordinate → Execute with G0–G3 gates |
| [impact-map-diagram.md](impact-map-diagram.md) | Visual example of an impact map (repos + dependencies) |
| [linkedin-summary.md](linkedin-summary.md) | Short social copy introducing chevp-workflow |
| [elevator-pitch.md](elevator-pitch.md) | 60-second pitch for the framework |
| [architecture-diagram.md](architecture-diagram.md) | System-level architecture illustration prompt |

## How to use

1. Open the prompt file.
2. Refine wording, constraints, and desired style.
3. Paste into your image/text tool of choice.
4. Save the output under `docs/images/` (or wherever applicable) and commit.
