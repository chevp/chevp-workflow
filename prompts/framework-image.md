## Prompt

Create a minimal technical illustration showing a workspace-level orchestration layer sitting above multiple independent git repositories.

**Visual elements:**
- Top band: a single horizontal "workspace" layer labeled "chevp-workflow" with violet/indigo glow
- Middle: 4–5 small repo icons side by side, each labeled (repo-a, repo-b, repo-c, repo-d), connected upward to the workspace layer by thin lines
- Dependency arrows between repos (repo-a → repo-b) to suggest commit sequencing
- One repo highlighted (thicker border, violet accent) to indicate "primary owner"
- Subtle grid background
- Dark slate-950 background, glass-panel style

**Color palette:**
- Background: `#020617` (slate-950)
- Workspace layer: violet gradient `#a78bfa → #6d28d9`
- Repos: slate-800 with subtle arctic accents
- Primary-owner highlight: violet-500 `#8b5cf6`
- Connecting lines: slate-600 with violet glow on the owner path

**Typography:** thin sans-serif (Inter), labels in slate-300

**Mood:** clean, structural, orchestration, calm authority.

No photorealism. No people. No code snippets in the image.
